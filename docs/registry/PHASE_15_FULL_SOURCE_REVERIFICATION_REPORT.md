# Phase 15 — Full Source Reverification Report

Every current operator's official crawler documentation was re-fetched live during this phase
(via a real HTTP fetch against the operator's current URL, not the repository's stored copy), per
Section 6/7's live-research requirement. The pending Amazon/Google correction notes from prior
phases were treated as research leads only and independently reconfirmed here, not blindly
published.

## Methodology

For each of the 9 registered operators, the current official source URL on file was fetched live.
Where a page redirected, the redirect chain was followed and recorded. Where a page could not be
read directly (JavaScript-rendered), that is disclosed rather than treated as a passing
verification. No third-party aggregator, SEO blog, or AI-generated summary was used as principal
evidence for any token, purpose, or lifecycle claim — only the operator's own current page.

## What this reverification pass does not cover

- **Googlebot's own dedicated page** (`developers.google.com/.../googlebot`, distinct from the
  `google-common-crawlers` page fetched above) was not independently re-fetched this pass —
  Googlebot's continued existence and `search` purpose was cross-confirmed as a byline mention on
  the `google-common-crawlers` overview page fetched. Disclosed as a minor scope gap rather than
  silently assumed complete.
- **IP/rDNS verification was not implemented as a registry field this phase** — the
  `publishedIpInfo` column already exists and is carried through the canonical snapshot, but no
  new automated IP-verification tooling was built. The rDNS/IP-list URLs discovered above
  (Anthropic, Common Crawl) are recorded here for a future phase, not acted on.
