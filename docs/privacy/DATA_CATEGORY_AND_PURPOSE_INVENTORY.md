## Notes

- IP addresses are never stored raw — only an HMAC-SHA256 hash keyed by `SESSION_SIGNING_SECRET`,
  used transiently for rate-limiting and stored only as the hash in `security_events.ipHash`.
- No `localStorage`/`sessionStorage` is used anywhere in the application.
- This inventory intentionally does not include actual customer data — it is a schema-level
  record, verified against `packages/database/src/schema/*` and the relevant `apps/web/src/lib/*`
  modules, not a data export.
