## Notes

- ~~Preview's `PUBLIC_SITE_URL`/`WEBAUTHN_RP_ID`/`WEBAUTHN_RP_ORIGIN` are placeholders~~
  **Resolved 2026-07-27** — all three now point at the real, confirmed-live
  `crawlpact-web-preview.rmtlbandara.workers.dev`.
- **Migration in progress (this pass): preview is moving off `workers.dev` onto the
  CrawlPact-owned Custom Domain `preview.crawlpact.com`.** `apps/web/wrangler.jsonc`'s
  `env.preview` now declares a `routes` entry (`{ pattern: "preview.crawlpact.com",
custom_domain: true }`) and `PUBLIC_SITE_URL`/`WEBAUTHN_RP_ID`/`WEBAUTHN_RP_ORIGIN` now point at
  it. This is required before Google OAuth preview testing can be configured — Google Auth
  Platform needs a stable, real origin to register. **Not yet live**: the Cloudflare Custom Domain
  still needs to be attached by an account owner (Workers & Pages → `crawlpact-web-preview` →
  Settings → Domains & Routes), after which Google Auth Platform needs
  `https://preview.crawlpact.com` added as an Authorized JavaScript origin and
  `https://preview.crawlpact.com/api/auth/google` as an Authorized redirect URI. Until the
  Custom Domain is live, WebAuthn ceremonies against `preview.crawlpact.com` will fail (the
  hostname won't resolve yet) — deploy only after the Cloudflare step is confirmed active.
- **Both environments have `workers_dev` enabled** (Wrangler's default when not explicitly set).
  Production has a working Custom Domain, so its `workers.dev` exposure is redundant — see
  `CLOUDFLARE_CONFIGURATION.md`'s dashboard checklist. Preview currently depends on it and will
  keep it as a temporary fallback during the Custom Domain migration above.
- The `SESSION` KV binding exists solely to satisfy `@astrojs/cloudflare`'s own built-in session
  feature default — it is not read by any CrawlPact application code (real sessions are D1-backed,
  ADR-0004). See `CLOUDFLARE_CONFIGURATION.md` for the full explanation.
