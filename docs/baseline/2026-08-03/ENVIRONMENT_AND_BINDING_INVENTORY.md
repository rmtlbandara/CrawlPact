## 3. CI environment (`.github/workflows/ci.yml`)

All CI env values are explicit, clearly-labelled placeholders (`ci-placeholder`,
`pri_ci_placeholder`) — no real credential of any kind is required to run CI. Confirmed
`AUDIT_ENGINE_ENABLED` is set to `"true"` specifically for the `browser-smoke` job's E2E run (both
as a job-level `env:` override and inside the generated `.dev.vars`), while the `quality` job does
not set it at all (inherits the top-level `env:` block's `"false"`) — this is a deliberate,
job-scoped override, not an inconsistency: `quality` never boots a live server so the flag is
inert there, while `browser-smoke` needs the real-scanner code path exercised.
