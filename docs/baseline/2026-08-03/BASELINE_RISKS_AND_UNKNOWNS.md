  unchanged this session; per this project's own standing guidance, GA supersedes the SRS ban by
  explicit product-owner decision and should not be removed.
- Workers Free CPU-budget risk for scan/monitoring (`docs/operations/SCAN_CAPACITY_BUDGET.md`) —
  reconfirmed as an accepted, not resolved, tradeoff now that the engine is live.

  job — reconfirmed unchanged.
- Agency-branding logo objects in R2 can become orphaned on bulk revoke/account-deletion purge —
  reconfirmed unchanged.
- Real paid Paddle checkout lifecycle has never been run — reconfirmed unchanged, still requires
  separate explicit authorization.
- Paddle webhook secret returned in plaintext by Paddle's own API shape, not rotated — reconfirmed
  unchanged (not requested or read during this session's live Paddle check, per Phase 0 secret
  rules).
