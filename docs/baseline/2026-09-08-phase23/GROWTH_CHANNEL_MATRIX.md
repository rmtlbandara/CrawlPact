## Why every row is `INVESTIGATE`/`DEFER`, not `READY`

Per Section 39's own instruction, a channel is only approved after its _specific, current_ rules
are read and its fit confirmed — not from a generic category match. This document identifies which
categories are worth that per-channel review; it does not substitute for it. Promoting a row to
`READY` requires the owner (or an agent explicitly directed to do so for one named community) to
actually read that community's current posting rules and confirm a genuine value-fit, immediately
before any post — not weeks in advance from a generic list like this one.
