# Documentation Archive

**Level 4 document (Historical and archived material).** This directory holds documents that
explain a past state of CrawlPact but are not authoritative for the current product. Every file
here (or in a subdirectory) begins with a historical notice stating its original date, archive
date, replacement document, and reason archived.

For current, authoritative documentation, start at `docs/README.md` or
`docs/status/CURRENT_STATE.md`.

## Subdirectories

- [`implementation-history/`](./implementation-history/README.md) — superseded implementation
  status logs, "Final" audit/compliance/readiness reports, and completed-workstream reports from
  before Phase 1 (2026-08-03) established the current source-of-truth hierarchy.
