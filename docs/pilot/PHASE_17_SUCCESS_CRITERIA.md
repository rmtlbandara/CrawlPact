# Phase 17 Success Criteria

Status: current-authoritative. Frozen **before** any pilot outcome is reviewed (§16/§118/§119) —
these are the Phase 17 prompt's own recommended defaults, adopted as-is since no other
owner-approved thresholds existed prior to this phase. Adopting them here, in writing, before
recruitment begins, is itself the anti-hindsight-bias step required by §118.

## Recommended evidence floor (adopted)

```text
External pilot participants:            >= 8   (preferred target 10-15)
Primary commercial segment (agency/multi-site) participants: >= 4
Core audit completion without help:      >= 75%
Saved-baseline activation:               >= 60%
Core end-to-end journey without major human intervention: >= 70%
Independent real paying customers:       >= 2
P0/P1 unresolved integrity blockers:     = 0
```

"Primary commercial segment" means agencies or genuine multi-site operators — internal/owner/
team/test accounts never count (§17, §24).

## Observation window

Minimum 14 days; preferred 30 days when practical (§20) — long enough to observe Pro/Agency
weekly monitoring more than once and to make return behaviour measurable. Solo's monthly cadence
may not be fully observed within 30 days; if Phase 18 must begin before a complete monthly cycle,
`docs/pilot/PHASE_17_PILOT_READY_AWAITING_EXTERNAL_EVIDENCE.md` (or the eventual completion
report) must explicitly say so (§21) rather than hide the limitation.

## Amendment policy

If any threshold above needs to change after real evidence starts arriving:

1. Record the **old** threshold here (struck through, not deleted).
2. Record the **new** threshold and the date of the change.
3. Explain why, with reference to what was learned.
4. Never present the new threshold as if it were the original.
