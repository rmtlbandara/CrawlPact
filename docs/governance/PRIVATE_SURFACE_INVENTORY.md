# Private Surface Inventory

**Level 2 document.** Phase 13. Every private production surface — grouped by area, matching
`apps/web/src/pages/{app,admin}` structure.

| Area                        | Routes                                       | Protection                                                  | Notes                                                                                                                                                                             |
| --------------------------- | -------------------------------------------- | ----------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| App (authenticated product) | `/app/*`                                     | Session cookie, `requireSession`                            | `noindex`, `no-store`, never GA                                                                                                                                                   |
| Admin (Super Admin)         | `/admin/*`                                   | Session cookie + `isAdmin`, `requireAdminSession`           | `noindex`, `no-store`, never GA                                                                                                                                                   |
| Billing                     | `/app/billing/*`, `/api/billing/*`           | Session                                                     | Never GA; Paddle API secret server-side only                                                                                                                                      |
| Domain history              | `/app/domains/*`, `/api/domains/*`           | Session, owner-scoped queries                               | Never GA                                                                                                                                                                          |
| Agency workspace            | `/app/workspace/*`, `/api/workspace/*`       | Session, plan-gated                                         | Never GA                                                                                                                                                                          |
| Notifications               | `/app/notifications`, `/api/notifications/*` | Session                                                     | Never GA                                                                                                                                                                          |
| Private Atom feed           | `/feed/[token].xml`                          | Feed token, entitlement re-checked on every read (Phase 10) | `Cache-Control: private, no-store`, never GA                                                                                                                                      |
| Private shared reports      | `/shared/[token]`                            | Revocable share token                                       | `noindex`, never GA                                                                                                                                                               |
| APIs (general)              | `/api/*`                                     | Varies — session, admin, or explicit anonymous rate-limit   | `X-Robots-Tag: noindex`, never renders `MarketingLayout` so structurally cannot load GA                                                                                           |
| Internal docs               | `docs/`                                      | Private GitHub repository                                   | Never routed publicly (`pnpm repo-privacy:validate` confirms no `.md` file exists under `apps/web/public/`)                                                                       |
| GitHub                      | Repository, Actions, PRs                     | Private repo, confirmed via `gh api`                        | See `docs/governance/PHASE_13_REPOSITORY_EXPOSURE_AUDIT.md`                                                                                                                       |
| CI artifacts                | GitHub Actions artifact uploads              | Private repo — Actions artifacts inherit repo visibility    | Bounded retention (14–90 days depending on artifact); never a full source tree, `.env`, or `.dev.vars` — see `docs/security/PHASE_13_REPOSITORY_SOURCE_EXPOSURE_THREAT_REVIEW.md` |
